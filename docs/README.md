# Public Mini Site

GitHub Pages-ready static site for the Hama AI Marketing Team Agents mini experience.

## Included mini experience

- Campaign ID: `2026-06-penalty-sms`
- Mini experience ID: `MINI-2026-06-penalty-sms`
- Route: `/mini/2026-06-penalty-sms/`
- Data file: `/data/MINI-2026-06-penalty-sms.json`

## Publish with GitHub Pages

1. Copy or commit the `public-mini-site/` folder to the repository or Pages branch.
2. Configure GitHub Pages to publish this folder, or copy its contents to the Pages root.
3. Open the generated URL:

```text
https://<github-user>.github.io/<repository>/mini/2026-06-penalty-sms/
```

4. Verify that the page opens publicly, the simulation notice is visible, and no personal information is requested.
5. Record the verified URL in:

```text
campaigns/2026-06-penalty-sms/production_data_manifest.template.json
```

Set `production_public_url` to the real URL and `public_url_checked` to `true` only after manual verification.
